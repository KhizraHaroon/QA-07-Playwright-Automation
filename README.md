# QA Automation Labs – Test Automation Framework

Automation project for **Assignment No. 7 – Selenium/Playwright Automation**, built with **Playwright + TypeScript** using the Page Object Model (POM) pattern, targeting the [QA Automation Labs Shop](https://shop.qaautomationlabs.com/) demo e-commerce site.


## Features Covered

1. Login failure scenario with error message validation
2. Successful login flow with homepage element validation
3. Product category navigation and product detail validation
4. Reusable utility functions
5. Page Object Model design pattern

## Running the Tests

Run all tests:

```bash
npx playwright test
```

Run tests in UI mode:

```bash
npx playwright test --ui
```

Run tests in debug mode:

```bash
npx playwright test --debug
```

## Test Report

To view the HTML report after running the tests:

```bash
npx playwright show-report
```
